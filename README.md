# Okdesk Assistant

Панель быстрых ответов и сценариев поверх оригинального Android-приложения Okdesk.

## Возможности

**Плавающая панель.** Сворачиваемая панель поверх оригинального приложения `ru.okdesk.mobile`.

**Редактор сценариев.** Текст, видимость комментария, статус, порядок шагов и селекторы элементов.

**Контроль выполнения.** Подготовка без отправки, пошаговый режим, остановка и локальный журнал.

**Импорт и экспорт.** Обмен сценариями в JSON с проверкой и обработкой дубликатов.

## Установка

Установите APK и оригинальный Okdesk. Откройте Assistant, прочитайте описание доступа и включите службу в специальных возможностях Android. Если Android ограничивает настройки приложения из APK, сначала разрешите их в сведениях о приложении. Откройте карточку заявки в Okdesk и разверните панель OA. Проверьте ограничение номера заявки в настройках до первого запуска.

## Статус выпуска

Приложение управляет экраном через Accessibility: разрешение позволяет читать содержимое и выполнять нажатия. API-ключ, root и разрешение сети не используются. Сценарии могут отправлять комментарии и менять статусы; остановка не отменяет уже выполненное действие. Изменение интерфейса Okdesk может потребовать настройки сценария. APK подписан debug-сертификатом; сборка и lint ранее прошли (0 ошибок, 14 предупреждений), повторной проверки на телефоне при открытии репозитория не было.

Контрольные суммы и сопроводительные лицензии находятся в файлах релиза.

## Сборка из исходников

```powershell
.\gradlew.bat lintDebug assembleDebug --no-daemon --console=plain
```
