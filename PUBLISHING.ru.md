# Публикация OkdeskAssistant 0.1.11

Дата: 2026-10-22. Репозиторий private; доступ к исходникам и APK имеют владелец и приглашённые пользователи GitHub. Ссылка сама по себе не предоставляет доступа. API-токены, пароли, keystore, local.properties, кэши Gradle, старые APK и рабочие данные в Git не включаются.

Версия APK: 0.1.11, сборка debug, для ограниченной проверки. Это не подписанный production-релиз. APK подписан существующим локальным Android debug-сертификатом; сам keystore не распространяется. Установка и работа на реальном устройстве в этой передаче не проверялись. Для production нужна отдельная подпись и аппаратная проверка.

Среда: JDK 17, Android SDK Platform 35, Build Tools 35.0.0, Gradle 8.11.1, Android Gradle Plugin 8.9.2. Команда проверки:

```powershell
$env:ANDROID_HOME = 'C:/path/to/Android/Sdk'
.\gradlew.bat --offline lintDebug assembleDebug --no-daemon --console=plain
```

В текущей среде первая попытка остановилась на Java Unix-domain loopback. Установка JVM-параметра jdk.net.unixdomain.tmpdir на существующую короткую локальную папку устранила ошибку. Этот машинный путь не записывается в настройки проекта. При первой сборке без локального кэша уберите --offline.

Собственная лицензия действует только в области LICENSE-SCOPE.md. Исходные тексты сторонних лицензий и notices сохранены.

Версия и программное поведение сохранены. Старые сведения README о действиях на телефоне относятся к прежним проверкам; в этой передаче сценарии Accessibility на реальном Okdesk не запускались. Приложение может отправлять комментарии и менять статусы только при выполнении пользователем сценариев; режим подготовки и ограничения заявок сохранены.

Итог: lintDebug и assembleDebug PASS; ошибок lint нет, предупреждений 14. Их список: ApplySharedPref, ClickableViewAccessibility, DataExtractionRules, RtlHardcoded, SetTextI18n, StaticFieldLeak, UnusedAttribute. Предупреждения существующего кода не исправлялись в рамках переноса.
